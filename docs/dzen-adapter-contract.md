# Контракт подключения загрузчика статей

Обновление 2026-10-05 добавляет интерфейс состояния подключения, но не вход в Дзен. В этом выпуске нет работающего адаптера, отправки запросов в Дзен, импорта cookies или установки адаптера через HTTP.

После входа в нашу панель доступен раздел «Подключение аккаунта Дзен»: состояние сессии, пять настроенных каналов и отдельный признак проверки прав для каждого. Состояние всегда `NOT_CONFIGURED`, права не проверены, кнопка входа недоступна. Факт наличия канала в конфигурации не означает наличия доступа. Очередь по-прежнему возвращает `BLOCKED`.

## API

Оба новых маршрута требуют существующий Bearer-ключ сервиса:

- `GET /api/v1/integration`: account_key, adapter, session, capabilities, live_ready, channels, missing_steps.
- `GET /api/v1/integration/contract`: машиночитаемое описание контракта. Его можно скачать из панели.

На сервере используется префикс `/dz`. Эти маршруты только читают состояние; нельзя отправить `READY` с клиента, загрузить ключи или объявить канал проверенным. Секреты и путь к профилю в ответах отсутствуют.

## Интерфейс для разработчика

`product_kb.dzen_integration.ArticleAdapter` — Python Protocol без реализации и без подключения к воркеру:

- `connection_state(account_key)` возвращает статус, время проверки и проверенные channel_id.
- `submit(account_key=..., channel_id=..., idempotency_key=..., article=...)` описывает будущую передачу задания и возвращает квитанцию.

Статусы подключения: NOT_CONFIGURED, DISCONNECTED, EXPIRED, READY, ERROR. Статусы квитанции: DRAFT_VERIFIED, PUBLISHED_VERIFIED, FAILED, UNCERTAIN. Это словарь для будущего адаптера, а не уже работающие переходы очереди.

Будущая реализация должна определять account_key/channel_id из серверной конфигурации, проверять доступ до загрузки, исключать секреты из ответов и журналов, сохранять порядок блоков/изображений и подтверждать результат повторным чтением. Неоднозначный исход требует UNCERTAIN и остановки автоматических повторов. Текущий restart/retry очереди нельзя переносить на живой транспорт без доработки восстановления неопределённых исходов.

Включение реального транспорта, авторизация, проверка прав и адаптация статусов очереди остаются отдельной задачей в среде, где такое подключение разрешено. Этот контракт не является официальным API Дзена.

## Предпросмотр

HTML передаётся в sandbox iframe через srcdoc вместо blob URL. Скрипты в iframe остаются запрещены. CSP разрешает только встроенные data-изображения и стили; текст статьи экранируется на сервере.
