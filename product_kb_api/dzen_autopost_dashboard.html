Загрузка в Дзен не подключена

Подключить сервис

Вставьте личный ключ API сервиса. При локальном запуске он находится в %LOCALAPPDATA%\DzenAutopostService\api-token.txt; на сервере — в защищённом runtime-каталоге. Это вход в нашу очередь, авторизации в Дзен здесь пока нет. Ключ хранится только в памяти этой страницы.

Подключение аккаунта Дзен

Вход в панель и вход в Дзен — разные подключения. Статьи остаются в очереди до подключения загрузчика.

Модуль авторизации не установлен. Дополнительных действий от вас сейчас не требуется.
